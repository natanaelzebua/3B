Character Manager — TP3 (Java Visual SIH-6406)
Deskripsi

Character Manager merupakan aplikasi sederhana berbasis Java yang menerapkan konsep Object-Oriented Programming (OOP). Program ini menggunakan class, object, constructor, enum, encapsulation, getter, setter, dan method untuk mengelola karakter dalam sebuah game.

Pada pengembangan TP3, aplikasi diperluas dengan fitur Mana dan pengecekan status kehidupan karakter menggunakan method isAlive().
